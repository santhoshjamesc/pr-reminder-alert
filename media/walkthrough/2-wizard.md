# Step 2: Run the setup wizard

Click **Run setup wizard**. Answer the questions; if unsure, press Enter to accept the default.

| Question | Plain meaning | Safe answer |
| --- | --- | --- |
| GitHub username | Your name on GitHub | e.g. `octocat` |
| Repositories | Which repos to watch | Leave empty = all your PRs |
| Reminder interval | Minutes between nudges | 30 |
| Max reminders | Stop nagging after this many | 5 |
| Quiet hours | No messages at night | Turn on, 22:00 to 08:00 |

The first sync only **records what already exists** so you are not flooded with old alerts. This is normal.
