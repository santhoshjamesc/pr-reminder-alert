# Step 5: You're done

Click **Open dashboard** or the **PR Reminder** icon in the left sidebar.

- **Pause / resume** reminders any time (Command Palette, type `PR Reminder: Pause`).
- **Acknowledge alerts:** `Cmd+Alt+Shift+A` (Mac) or `Ctrl+Alt+Shift+A`.
- **Open dashboard:** `Cmd+Alt+Shift+P` (Mac) or `Ctrl+Alt+Shift+P`.

Stuck? Open the Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`) and run **PR Reminder: Show Service Logs**.
