# Step 4 (optional): WhatsApp reminders

1. Click **Link WhatsApp**. A Chrome window opens showing a QR code.
2. On your phone: WhatsApp, then **Linked devices**, then **Link a device**, then scan the code.
3. In the dashboard's **Reviewer mapping**, add each reviewer's number with country code, e.g. `+919876543210`.
4. Run **PR Reminder: Test WhatsApp Connection**.

Needs Google Chrome, Edge, Brave or Chromium installed. Keep message volume normal: WhatsApp does not officially support automation.
